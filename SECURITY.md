# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Cukupin™, please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Submit a private vulnerability report via [GitHub Security Advisories](https://github.com/rhaffle87/cukupin-v0/security/advisories/new).
3. Provide a detailed summary including reproduction steps, expected versus actual behavior, and potential impact.

We take security seriously and will investigate all legitimate reports promptly.
